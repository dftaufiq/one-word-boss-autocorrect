A tiny program that writes one word — Autocorrect — to /output/entry.txt, our entry for make.fun's "One Word for the Boss" bounty. The word describes the boss who "corrects" good work into something worse and can't be switched off, like autocorrect on a phone.

## Run it

```sh
node main.ts
```
